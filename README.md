# portfolio

This repository contains a minimalist portfolio website designed for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

After enabling GitHub Pages in the repository settings, the site will be published at:

`https://mathiu-06.github.io/portfolio/`
